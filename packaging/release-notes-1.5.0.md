# SwitchMonitor 1.5.0

SwitchMonitor now checks for updates at startup and every six hours. When a new release is available, **Install update** appears in the monitor tray menu. Selecting it downloads the installer, verifies its SHA-256 checksum against the published release manifest, installs the new version, and reopens the app. Existing monitor profiles, shortcuts, brightness settings, and the Start with Windows shortcut remain in place.

The tray menu retains **Check for updates** for an immediate manual check. Automatic installation is available in the installed edition; portable and source copies open the release page.
