# SwitchMonitor 2.0.1

Your computers and phones now work as one group, and the app is easier to find your way around.

## Windows

- **My devices.** Add a computer or phone once with a 6-digit code (it changes every 30 seconds and is the same code an authenticator app shows if you add the setup key) and one click of approval. After that the devices find and trust each other by themselves, even if an address changes. Each device has its own key; any computer can remove a device and the removal spreads.
- **Other computers' displays** appear in the panel with the same controls, with no label to tell them apart.
- **Settings → Devices** is split by way of connecting: connection, *My devices* (recommended), phone, shared mouse and keyboard, and *Pair one computer by code* (secondary, folded).
- **Shared mouse and keyboard** needs no side setting: push the pointer past either edge. *Restart as administrator* lets it control elevated windows.
- **Phone as mouse and keyboard** for this computer, smooth at the pace of your finger, and aimable at any computer in the group.
- **Apps tab:** drag a program to a display and it opens there (normal, maximized, half the screen, minimized). Working All / Used / System / User filters.
- **Welcome tour** (three slides) on first run and when features are added; the main window waits until you finish it.
- **Settings → General → Quick switches** gathers everything that turns on with a switch; **Settings → About** lists every feature by category.
- **Spanish** for panels, messages and errors, changed on the spot. Sub-tabs in Settings look different from the main menu. One style for every close (X) and check icon.
- Fixes: the pointer-light switch showed *off* while the light was on; the LG listed twice when two computers shared it; AMD writes are on by default.
- Monitors: Samsung Odyssey G5 (SAM7488).

## Phone (Android 6.0+)

- The app is the group's, not one computer's: controls for every display of every connected computer, a **Controls / Mouse** pair of tabs, and the volume of the computer that owns the selected display.
- Join the group with the code (*Add this phone*) or pair with one computer as before.
- **Mouse** tab: touchpad, buttons, scroll, keys and a keyboard for any computer of the group.

## Files

- `SwitchMonitor-2.0.1-win-x64.zip` — unzip and run `SwitchMonitor.exe` (no installation, .NET included). Settings: `%LOCALAPPDATA%\SwitchMonitor-v2`.
- `SwitchMonitor-2.0.1.apk` — install directly on the phone.

The builds are not code-signed. SHA-256 below. 2.0.1 keeps the 2.0.0 settings and pairings.
