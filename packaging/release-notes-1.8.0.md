# SwitchMonitor 1.8.0

The brightness panel now accepts a number from 0 to 100 for the selected display. Enter applies it immediately, two seconds without another digit applies it automatically, and Escape cancels it. The active display shows a countdown with a subtle circular glow; other display rows stay unchanged.

Tap `*` to select the next display, or hold it for one second to link or unlink brightness. Rapid keyboard adjustments move the slider immediately. The panel now distinguishes external monitors from laptop screens and uses the laptop model when Windows provides it.

Existing monitor profiles, shortcuts, brightness preferences, and Startup choice are preserved during an update.
