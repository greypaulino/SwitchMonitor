# SwitchMonitor 1.6.1

The brightness panel now closes before its final one-pixel frame reaches the Windows 11 taskbar, addressing a white flash during exit. Independent monitor sliders have more vertical space between rows.

Selecting **Check for updates** now notifies you when a new release is found, downloads its installer, and starts the verified upgrade automatically. Background checks still only announce available updates. The portable edition opens the release page instead of launching an installed-edition upgrade.

Existing monitor settings and shortcuts remain in the user data directory during installation.
