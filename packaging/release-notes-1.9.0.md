# SwitchMonitor 1.9.0

The brightness panel now offers a circled **M** beside each monitor. The white icon marks the main Windows display; click another monitor's icon to make it the main display. Settings has a **Main display** checkbox for the selected monitor, applied on Save. The choice is unavailable when Windows does not expose that display as an active, selectable screen.

Linking brightness now adopts the highest percentage shown by the individual sliders and adjusts lower monitors before showing the shared slider. Independent and linked layouts have aligned labels, percentages, and icons; the panel has rounded upper corners. The new main-display icon uses a multi-size ICO asset.

Rapid brightness taps advance to five-point marks, while sustained presses advance to ten-point marks. The panel's paint and close sequence was also hardened against an intermittent error during redraw. Existing monitor profiles, shortcuts, brightness preferences, and Startup choice are preserved during an update.
