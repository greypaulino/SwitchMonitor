SWITCHMONITOR 1.10.0

Install SwitchMonitor-Setup-1.10.0.exe on each computer. AutoHotkey and ControlMyMonitor are included. The portable ZIP can be extracted and run without installation.

FIRST USE
1. Select a monitor when more than one is detected.
2. Check the inputs you use. Next input cycles through checked inputs only.
3. Click an input's shortcut button to record a combination of 2 to 4 keys. Press Escape or Delete to clear it.
4. Set the global shortcuts if desired. Defaults: Ctrl+Alt+M for Next input; Ctrl+Shift+Alt+M for Settings.
5. Choose Save. If nothing changed, choose Close.

The tray menu lists monitors, then Settings, Shortcuts, Next input, Check for updates, About, Start with Windows and Exit. Input shortcuts from all saved monitor profiles stay active. Settings and Shortcuts open for the selected monitor. Duplicate shortcuts across monitors and global actions are rejected.

When a newer GitHub release is available, a Windows notification and the monitor tray menu offer the update. An update is downloaded and installed only after you click the notification or "Update available! Click to install". The installer is verified before installation; user settings are preserved.

BRIGHTNESS CONTROL
Click the sun icon in the tray to open or close a slider for each detected monitor. The default shortcuts are Ctrl+Alt+- (down), Ctrl+Alt++ (up), and Ctrl+Alt+* (next monitor). The numeric keypad works for all three; on a US keyboard the main-keyboard alternatives are -, Shift+=, and Shift+8. Edit these shortcuts in Settings if needed.

An isolated tap or mouse-wheel step changes one point. The third rapid tap (less than 167 ms apart) moves to the next five-point mark. Holding a brightness key reaches the next five-point mark after 300 ms, then advances by ten-point marks from 500 ms onward. Linking brightness first raises lower displays to the highest displayed percentage, then shows one shared slider. A built-in laptop display uses Windows brightness control and has no input shortcuts. With multiple displays, hover over one or press * to move the active highlight. Small or rapid slider changes respond immediately; larger jumps animate smoothly. The panel slides away after five seconds without interaction and stays open while the pointer is over it.

The circled M beside each monitor identifies the main Windows display. Click another M to make that display the main one. Settings also offers a Main display checkbox for the selected monitor; choose another monitor, check it, and save to apply the change. The checkbox is disabled when Windows does not permit selecting that display.

With the brightness panel open, hold M for more than half a second to change the main display. Type a brightness percentage from 0 to 100; one second after the last digit it is applied, or press Enter to apply immediately. Escape cancels the entry. The numeric overlay shows the value without a countdown.

In an extended desktop, cycling the main monitor to another computer moves the main display to a remaining screen. When that monitor returns to its original input, SwitchMonitor restores its main-display status. This does not run in PC screen only or Second screen only modes.

The connected-input checkboxes are manual. They do not detect whether the other computer is powered on.

Settings are preserved when the app is updated or removed.
