# SwitchMonitor 1.10.1

When two displays are detected but Windows is using only one, the inactive display appears as a compact `OFF` row in the brightness panel. Its slider is hidden, and keyboard or pointer selection skips it. Chain and main-display controls are unavailable until both displays are active again. The panel refreshes when Windows changes display mode.

The installer preserves settings in `%LOCALAPPDATA%\SwitchMonitor`.
