# SwitchMonitor 1.6.4

The brightness panel now paints its controls before fading into view, preventing the entrance flicker confirmed on Windows 10. The larger active-monitor indicator and additional spacing in linked mode make multiple monitor names easier to read.

Update notifications now cover download and installation. After a successful upgrade, SwitchMonitor shows the installed version in a popup that closes after two seconds. Existing settings stay in the user data directory.

Please test the panel entrance on Windows 11; this fix was validated locally on Windows 10.
