# SwitchMonitor 1.6.2

Update checks now notify without downloading. Click the Windows notification or **Update available! Click to install** in the tray menu to start a verified installation.

Linked brightness shows monitor names on separate lines while keeping the percentage in place. The link control is hidden in the brightness panel and disabled in Settings when only one monitor is detected.

The brightness panel suppresses the Windows 11 compositor border during its entrance animation. Its settings icon now paints an opaque dark background before blending the icon, preventing intermittent white shading.

Existing monitor settings and shortcuts remain in the user data directory during installation.
